# 医药板块 · 集采冲击 · 困境反转 vs 价值毁灭 · 2018—2022

## 事件经过

### 背景：国家药品集中采购（带量采购）制度

2018年11月，"4+7"城市带量采购试点启动，对进入医保目录的仿制药进行集中招采，通过"以量换价"大幅降低药品价格。这一政策对医药行业产生了深远影响——但不同类型的公司受到的影响截然不同。

### 时间线

| 时间 | 事件 | 市场影响 |
|---|---|---|
| 2018年11月 | "4+7"带量采购首次中标结果公布（降价幅度远超预期，最高降幅90%+） | 仿制药公司暴跌，医药板块整体回调 |
| 2019年 | 集采范围扩大至全国（"4+7"扩面），频率加快 | 恐慌情绪持续，仿制药持续承压 |
| 2020年 | 第三批、第四批集采（高值耗材也开始集采，心脏支架等降价90%+） | 范围扩大至器械，市场预期进一步悲观 |
| 2020-2021 | CRO（药物研发外包）/ 创新药服务赛道逆势大涨（集采驱动研发需求） | 医药内部严重分化 |
| 2021年 | 医药板块短暂反弹（顺周期+疫苗逻辑） | 部分公司业绩超预期 |
| 2022年 | CRO板块暴跌（美国Biosecure立法担忧+行业景气下行） | 前期涨幅最大的医药细分反转 |

### 集采对不同医药子行业的差异化影响

| 子行业 | 受集采影响程度 | 业务逻辑变化 |
|---|---|---|
| 仿制药（化学药） | **极大**：核心产品直接降价60-90%，利润腰斩 | 商业模式根本改变（量增价跌，利润薄如纸）|
| 创新药 | **中等**：已过专利期或即将过期药品集采，但在研新药不受影响 | 加速研发转型，投入上升但预期改善 |
| 中药（独家品种）| **较小**：独家品种通常不参与集采 | 国家推广中医药叠加，逻辑反而改善 |
| 医疗器械（耗材） | **极大**：心脏支架降价93%，骨科耗材类似 | 销量增加但利润大幅压缩，分化大 |
| CRO/CMO（外包服务） | **受益**：集采迫使药企转向创新药，研发外包需求大增 | 短期受益，后期担忧法规/政策风险 |
| 医疗服务（医院/体检） | **间接受益**：集采降低药品成本，利于医院运营 | 相对防御 |

## 各方观点

### 邱国鹭框架（行业分类）

**集采正式启动（2018年底）时的行业定性**：

- **仿制药**：从"低估改善"区间迅速滑入"低估恶化（价值陷阱）"——
  - 集采不是一次性冲击，是**系统性制度变化**，改变了整个商业模式（高毛利仿制药→低利润率大批量）
  - ROE长期下行，护城河被政策彻底侵蚀
  - 邱国鹭框架：**不符合"低估改善"定义，是真正的价值陷阱**

- **创新药/CRO**：进入"中位成长"区间——
  - 集采倒逼药企加大创新研发，利于CRO赛道
  - 创新药专利期内不受集采影响
  - 短期估值较高，但有增长支撑

- **独家中药**：从"中位平稳"向"低估改善"迁移——
  - 集采不覆盖，政策受益（国家扶持中医药）
  - 被市场连带错误打压，出现阶段性低估机会

### Howard Marks逆向框架

**关键判断**：集采冲击是"一次性冲击"还是"结构性损毁"？

对于仿制药：→ 结构性损毁（不适合逆向买入）
- 集采是永久性政策，不会退出
- 每年都有新批次集采，仿制药利润持续侵蚀
- 护城河（高定价权）被制度性消灭

对于独家品种中药/医疗服务：→ 一次性的"情绪连带下杀"
- 被市场情绪错误连带下跌，但基本面未受集采直接影响
- 若估值足够低，符合逆向买入条件

### 唐朝框架（三问）

**对仿制药的三问**：
1. 三年后市场地位基本确定？→ **不确定**（集采每年扩围，市场份额和利润都难以稳定）
2. 三年后利润大概率比现在高？→ **否**（集采导致利润持续压缩）
3. 现在估值便宜？→ 即便PE低，也是利润持续下滑的"低PE陷阱"

→ **唐朝框架：直接放弃，不做深度研究**

**对创新药龙头（如药明康德）的三问**（2020年）：
1. 三年后市场地位基本确定？→ **大概率是**（全球MNC外包给中国CRO的趋势强劲）
2. 三年后利润大概率比现在高？→ **是**（收入增速20-30%，护城河强）
3. 现在估值便宜？→ **PE 60-80x，不便宜**（买点需要等待回调或接受成长溢价）

### 姜诚框架（深度价值）

**对集采医药的态度**：
- 对仿制药：PE再低，也不是便宜——因为ROE正在系统性下滑，"便宜"是伪命题
- 对中药独家品种：若因集采情绪连带被压制至历史PE低分位，且基本面完整，符合深度价值框架
- 核心判断标准：这个低估是"暂时性情绪错误"还是"正确的永久性折价"？

## 为什么混合结果

### 判断正确的部分

- **仿制药是价值陷阱**：最终验证，集采政策确实是系统性的，主要仿制药公司利润持续下滑，部分股价长期阴跌（即使便宜也错）
- **CRO受益于集采**：药明康德/康龙化成等2019-2021年大幅上涨，验证了"集采倒逼创新研发"的逻辑
- **独家中药品种回调后存在机会**：云南白药/片仔癀等因情绪连带被打压，但基本面未受集采影响，2020年以后有较好表现

### 判断错误的部分

- **CRO赛道2021年后的过度乐观**：CRO公司2021年PE高达100x+，Biosecure法案（2023年）担忧进一步打压，证明赛道好≠任何价格可买
- **创新药的研发风险被低估**：部分创新药研发失败导致个股暴跌，行业β中藏着大量个股α风险
- **集采速度超预期**：市场2018年以为集采是小范围试点，实际上快速扩展至所有主要仿制药和高值耗材，悲观者低估了政策执行力度

## 可复用规律

### 规律1：政策性"行业分化"是选股的最佳来源

同一个板块内，政策打击的方向往往是高度具体的（仿制药≠创新药，普通耗材≠高壁垒设备）。
- **可操作**：政策冲击后，第一步分析"谁真正受影响"，而非对整个行业一刀切

### 规律2：仿制药式"利润陷阱"的识别

以下情况PE低不等于便宜：
- [ ] 核心业务的定价权被政策系统性消灭（集采、药价管控）
- [ ] ROE已连续多年下滑，且趋势不可逆
- [ ] 行业整体竞争格局正在恶化（集采迫使企业拼量不拼价）
- [ ] 业务模式依赖政策保护（而非真实竞争优势）

**口诀**：PE 10x但ROE 5%且持续下滑，不如不买

### 规律3：政策受益方往往在政策公布的混乱期被低估

集采对CRO的利好（迫使药企转向创新研发→研发外包需求增加）在2018年初期没有被市场充分认识。
- **可操作**：政策出台后，认真思考"政策链条"中的受益者（不只是受损者）

### 规律4：连带下跌中寻找"误伤"机会

- 集采公告后，中药独家品种、医疗服务、创新药都因"恐慌情绪"受到波及
- 误伤的判断标准：这家公司的核心业务是否真正受到该政策直接影响？
- 若否 + 估值已到历史低位 → 误伤型逆向机会

### 规律5：CRO类"赛道好公司"的估值风险

- 基本面好≠任何估值可接受
- CRO在PE 100x时已是"确定性的透支"，即使行业继续增长，股价也需要时间消化估值
- **可操作**：赛道好公司的买入也要有PEG<1.5的纪律

## 反例（不适用场景）

1. **"集采=所有医药公司都应回避"**：独家中药/CRO/医疗服务在集采期间表现分化极大，一刀切回避是认知错误

2. **"仿制药跌多了就是机会"**：华海药业/恒瑞医药的案例说明，集采不是一次性冲击，低PE仍然是陷阱

3. **"创新药一定是好赛道"**：创新药研发失败率极高（临床III期失败率接近50%），赛道好不代表个股风险低；不做深度研究的"赛道投资"在创新药行业特别危险

4. **"集采过了就安全了"**：即便某个产品已完成集采纳入，下一批集采仍然可能再次压价，仿制药公司的利润压力是持续的，没有"安全线"

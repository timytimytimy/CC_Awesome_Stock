# 里海研究体系 · 单股研究清单

> 来源：里海的朋友们专栏（付费课程笔记整理版，2026-05-21）
> 使用说明：本清单作为辅助研究工具，不作为买卖信号依据；所有判断必须结合财报、行情和个人能力圈。

---

## 一、六问分析法（研究主线）

在开始任何个股研究前，先回答这六个问题：

1. **这家公司到底靠什么赚钱？** → 一句话能说清楚利润来源（否则不研究）
2. **过去几年利润/现金流/股价为什么这样变化？** → 还原历史，找真实驱动因子
3. **未来推动公司重新定价的核心变量是什么？** → 不是"公司好"，而是"什么会改变市场认知"
4. **这个变量是否足够大，是否已被市场充分定价？** → 大家都知道的好故事，预期差消失
5. **如果看错，亏损边界在哪里？** → 证伪条件、止损位、安全边际
6. **买入、持有、卖出的证据链分别是什么？** → 三个阶段必须有不同标准

## 二、数据源与取数纪律（取数前置）

> 里海的取数原则：宁可慢，也要用权威原始源。东财/同花顺是转手加工版——
> 财务排雷和六问的"事实"层若建在二手数据上，结论再严谨也可能是错的。

### 源的优先级（从高到低）

1. **官方原始源（首选，可作 [事实]）**
   - **巨潮资讯 cninfo（cninfo.com.cn）**——证监会指定法定披露平台，
     财报、公告、招股说明书、业绩预告首发且权威。
   - **上交所 / 深交所（sse.com.cn / szse.cn）**——交易所公告、问询函、交易统计。
   - **公司官网**——业务介绍、投资者关系、产品与订单动态。
2. **券商 / 三方的"数据"（可交叉验证，但不取观点）**
   - 中信等券商、东财、同花顺、新浪——只用其**主要财务指标**做交叉核对。
   - ⚠️ 券商的**评级、目标价、荐股观点不取**——只借数据，不借结论。
3. **加工聚合源（便利，但存疑要回原始源核）**
   - akshare 等取数库本质是对上述源的转手；数据存疑时回巨潮/交易所核原文。

### 必做的取数动作

- **上市 10 年以内的公司：必读招股说明书。** 招股书是一家公司信息最全的单一文件——
  商业模式、行业格局、竞争地位、风险、历史财务、募投方向全在里面，是理解年轻公司
  "创立逻辑和原始竞争位置"的最快路径。巨潮上免费可得。
- **交易所问询函是风险信号。** 公司被交易所发问询函（尤其针对财务、并购、业绩），
  必须列入财务排雷和反对理由。
- 财报关键数字（营收/净利/现金流/ROE）若二手源之间打架，**以巨潮原文为准**。

> 一句话：**事实层只认官方原始源；券商只借数据不借观点；年轻公司先读招股书。**

## 三、财务排雷清单（必须前置，通过才深研）

以下任意一项红旗出现 → 降为"等待验证"或直接放弃：

- [ ] **关联交易**：大股东与上市公司体外关联方之间频繁资金拆借、代收代付、定价不公允
- [ ] **大存大贷**：账面货币资金巨大同时有息负债也巨大，且无合理解释（参考：康美药业）
- [ ] **现金流与利润不匹配**：净利润增长但经营现金流长期很差；应收账款/存货增速显著快于营收
- [ ] **商誉地雷**：高商誉且并购标的质量不明、业绩承诺期已过或不达预期
- [ ] **治理风险**：实控人高比例质押、资金占用、违规担保、频繁减持

**通过排雷才可进入深度研究阶段。**

## 四、20个必须回答的问题（深度研究清单）

| # | 问题 | 类别 |
|---|---|---|
| 1 | 公司主营业务是什么，能否一句话讲清利润来源 | 商业模式 |
| 2 | 过去5-10年营收、利润、扣非利润、经营现金流如何变化 | 财务历史 |
| 3 | 利润增长来自价格、销量、毛利率、费用率、资产注入、周期还是并购 | 增长拆解 |
| 4 | 经营现金流是否长期支持利润 | 利润质量 |
| 5 | 资产负债表是否有硬伤 | 财务安全 |
| 6 | 是否存在大存大贷、应收异常、存货异常、商誉过高 | 财务排雷 |
| 7 | 是否存在股权质押、关联交易、资金占用、治理问题 | 治理排雷 |
| 8 | 公司所处行业是成长、成熟、周期、困境还是政策驱动 | 行业判断 |
| 9 | 行业空间是否足够，天花板在哪里 | 赛道评估 |
| 10 | 公司行业地位是否清楚（龙头/隐形冠军/跟随者/边缘） | 竞争格局 |
| 11 | 核心变化是什么，变化是否足够大 | 驱动因子 |
| 12 | 变化是否已被市场定价（预期差在哪） | 赔率判断 |
| 13 | 起涨或当前市值是否仍有赔率 | 估值赔率 |
| 14 | 公司是战术机会还是战略机会 | 机会类型 |
| 15 | 买入逻辑是短逻辑、中逻辑还是长逻辑 | 时间维度 |
| 16 | 什么事实能证明逻辑错了（证伪条件） | 风险管理 |
| 17 | 什么价格或估值说明赔率不够（卖出估值条件） | 退出标准 |
| 18 | 什么财务指标必须持续跟踪 | 跟踪机制 |
| 19 | 什么市场结构能确认买点 | 技术确认 |
| 20 | 仓位上限是多少，为什么 | 仓位纪律 |

## 五、硬否决清单（直接降级，不给仓位）

出现以下任意一项 → 直接降为"放弃"或"只跟踪"：

- 利润从哪里来讲不清
- 公司跨行业太多，主逻辑不清
- 现金流长期差，利润质量无法解释
- 大存大贷无法解释
- 应收账款或存货增速显著高于收入
- 商誉巨大且并购标的质量不明
- 实控人高质押、资金占用、关联交易严重
- 只是低PE/PB，但没有未来改善逻辑
- 涨幅已经充分反映变化，赔率消失
- 逻辑需要多个假设同时成立
- **日线、周线、月线仍处明显下跌趋势，没有底部证据**

## 六、五类机会分类（决定研究深度和仓位）

| 类型 | 特征 | 操作 |
|---|---|---|
| **战略长周期强观察** | 商业模式简单、财务过关、大变化、未充分定价、低位结构成立 | 深度研究，可跟踪数月到数年，有条件重仓 |
| **战术强观察** | 有估值/困境/周期修复或短期催化，但长期空间不清 | 到位后要走，不能强行变长逻辑 |
| **等待验证** | 有逻辑，但缺关键证据（价格/基本面/财务/定价） | 记录，等待触发条件，不动仓位 |
| **放弃** | 太复杂/财务治理说不清/赔率消失 | 直接删除候选池 |
| **可买入仓位** | 长周期逻辑+赔率+财务安全+价格结构+证伪位同时满足 | 按仓位纪律执行 |

## 七、买点纪律

### 基本面买点
- 核心变化出现，但市场还半信半疑
- 财务报表开始验证，但估值尚未完全修复
- 低质业务收缩、高质业务增长
- 利润拐点出现，现金流同步改善

### 价格结构买点
- 月线或周线不再单边下跌
- 日线停止创新低
- 股价收复关键平台或均线
- 回调缩量，支撑有效
- 突破或反转有量能配合

### 仓位买点（三选一）
- **弱者视角**：有安全边际，看错亏不大（主要用证伪位控制）
- **强者视角**：真正看懂管理层、行业和长期空间（可接受不低估位置）
- **没有证伪位，不给大仓位**

---

## 八、卖出纪律

卖出不是因为涨了，而是因为以下之一：

- [ ] 基本面变差（而非股价下跌）
- [ ] 买入逻辑被证伪（核心假设失效）
- [ ] 短逻辑或中逻辑已经兑现（战术机会到位）
- [ ] 长逻辑空间明显收窄
- [ ] 估值已经极端透支（赔率消失）
- [ ] 市场情绪极度亢奋（拥挤交易）
- [ ] 出现无法解释的财务或治理风险

## 九、不同公司类型的研究重点

| 类型 | 重点关注指标 |
|---|---|
| **消费提价型** | 品牌力、提价幅度、消费者敏感度、合同负债、库存、毛利率、费用率 |
| **大营收小利润型** | 营收质量、低利润原因（结构性/阶段性）、费用率、规模效应 |
| **困境反转型** | 困境来源（经营/行业/财务/治理）、解除路径、时间成本 |
| **资产推动型** | 在建工程、资本开支、融资能力、产能释放节奏、毛利差 |
| **商业模式推动型** | 单店模型、复制能力、现金流、品牌、管理半径、并购质量 |
| **周期型** | 供需、价格、库存、集中度、成本曲线、正常化利润、景气顶部 |
| **科技成长型** | 行业扩容、产品迭代、客户结构、竞争格局、估值消化能力 |
| **国资/资产注入型** | 控股股东资源、承诺履约能力、资产质量、注入价格、同业竞争 |

## 十、复盘模板（每次交易后必答）

- 当初事实判断对不对
- 推理链哪里错了（行业/公司/财务/估值/买点）
- 有没有把短逻辑误当成长逻辑
- 有没有因情绪改变纪律
- 有没有买入能力圈之外的公司
- 有没有低估财务或治理风险
- 如果再做一次，仓位和买点怎么改

---

## 十一、里海核心认知 · 心态与能力圈

- **研究不等于投资**：研究只是还原事实，投资是在不确定中做判断
- **承认看不清**：散户不可能100%看清公司；找到漏洞能否理解和控制，是能否投的标准
- **追求简单**：决定利润的核心因子越少越好；复杂到解释不清的公司主动放弃
- **弱者/强者视角的选择**：能力圈内选强者（接受不低估），能力圈外选弱者（只要安全边际）
- **买入前必答**：如果下跌30%，我靠什么判断是否继续持有
- **价值投资的本质**：以基本面为锚，不是买白马，困境反转也属于价值投资

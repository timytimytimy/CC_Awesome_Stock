# 里海 · 散户基本面实践者

## 1. 一句话画像

从散户视角出发，用公开资料、财务常识和赔率思维，系统研究 A 股的普通投资者；方法论的核心是"看不清但有概率，承认局限再做判断"，而非追求完美研究。

## 2. 适合散户学习的部分

**研究框架**
- "六问分析法"：利润从哪来 → 过去为什么涨跌 → 未来核心变量是什么 → 是否已被定价 → 看错的亏损边界 → 买持卖的证据链
- 公司类型识别框架：消费提价型 / 大营收小利润型 / 困境反转型 / 资产推动型 / 商业模式推动型 / 周期型 / 科技成长型 / 国资注入型
- 战术机会 vs 战略机会的明确区分（短逻辑到位要走，不能强行变长逻辑）

**财务分析**
- 三表联动读法：利润表（可调节）→ 现金流验证 → 资产负债表交叉
- 五类财务排雷：关联交易、大存大贷、现金流与利润不匹配、商誉/减值、治理和质押
- "决定利润的前三个变量"框架：超过三个且都看不清，应谨慎

**投资哲学**
- 弱者视角 vs 强者视角的区分（弱者要安全边际，强者要真正理解管理层和行业）
- "频率低、赔率好、概率大"的核心约束
- 承认散户能力边界：复杂公司主动放弃，简单公司深度研究

**案例覆盖（12家公司详细分析）**
- 涪陵榨菜（消费提价型）、智飞生物（代理+特殊事件型）、博腾股份（CRO困境反转）
- 重庆啤酒（资产注入+管理改善）、利亚德（制造型战略股）、爱尔眼科（连锁商业模式）
- 川能动力（破产重整+业务转型）、坚朗五金（隐形冠军+利润释放）
- 卓胜微（科技国产替代）、中远海控（周期股+超级利润）
- 再升科技（高专业度材料）、新希望（周期+安全垫组合）

## 3. 不应学习或直接复制的部分

- 不直接照搬"弱者/强者视角"仓位判断——这依赖里海本人对个股的深度认知，散户复制时没有同等信息基础
- 课程案例都是历史成功案例（回顾偏差）：要警惕幸存者偏差，失败案例没有在课程中详细呈现
- 不把"核心变量是否被定价"当成可以快速判断的指标——这需要大量市场感知和行业数据
- 课程观点以定性分析为主，缺乏量化验证（没有回测数据）

## 4. 可复用执行流程

### 4.1 单股研究流程（里海六问）
1. 这家公司到底靠什么赚钱（一句话能说清）
2. 过去几年利润/现金流/资产负债和股价为什么这样变化
3. 未来推动公司重新定价的核心变量是什么
4. 这个变量是否足够大，是否已被市场充分定价
5. 如果看错，亏损边界在哪里（证伪条件）
6. 买入、持有、卖出的证据链分别是什么

### 4.2 财务排雷清单（前置，通过才深研）
- [ ] 无大股东关联交易异常（资金拆借/代收代付/定价不公允）
- [ ] 无大存大贷（巨额现金+高息负债共存无法解释）
- [ ] 经营现金流与净利润基本匹配（CFO/净利润 > 0.5，低于此需解释）
- [ ] 应收/存货增速未显著快于营收
- [ ] 商誉规模合理，并购标的质量可追踪
- [ ] 无实控人高质押、资金占用、违规担保
→ 任意一项红旗，降为"等待验证"，不做深度研究

### 4.3 五类机会分类（决定研究深度和仓位）
- **战略长周期强观察**：商业模式简单、财务过关、大变化+未充分定价+低位结构 → 可重仓
- **战术强观察**：有估值/困境/周期修复催化，但长期空间不清 → 设明确退出条件
- **等待验证**：有逻辑，缺关键证据（价格/基本面/财务风险未排除）→ 记录跟踪
- **放弃**：太复杂/财务治理说不清/赔率消失 → 直接删除候选
- **可买入仓位**：长周期逻辑+赔率+财务安全+价格结构+证伪位同时满足

### 4.4 公司类型对应研究重点
| 类型 | 核心关注 |
|---|---|
| 消费提价型 | 品牌力、提价幅度、消费者敏感度、合同负债、毛利率 |
| 大营收小利润型 | 低利润原因（结构性/阶段性）、费用率、规模效应 |
| 困境反转型 | 困境来源、解除路径、财务压力、治理风险、反转证据 |
| 资产推动型 | 在建工程、投产节奏、融资成本、毛利差、债务成本 |
| 商业模式推动型 | 单店模型、复制能力、现金流、品牌、并购质量 |
| 周期型 | 供需、价格、库存、集中度、成本曲线、正常化利润 |
| 科技成长型 | 行业扩容、产品迭代、客户结构、竞争格局、边际变化 |
| 国资/资产注入型 | 控股股东资源、承诺履约、资产质量、注入价格 |

## 5. 风险和失败模式

- **幸存者偏差**：课程案例全部是成功的大牛股，没有系统呈现失败案例；复用时需自行补充反例
- **时代背景依赖**：案例主要来自2013-2022年A股特定市场环境（创业板牛市、消费升级、新能源），当前背景未必同等适用
- **散户执行差距**：里海的"看懂核心逻辑再重仓"需要大量行业积累，散户在没有同等背景下强行复制容易出错
- **付费课信息特权**：课程内容为付费私域，公开讨论和验证有限，无法通过公开市场验证其历史观点准确率

## 6. 利益冲突与商业化

- 内容来源于付费专栏（"里海的朋友们"），有商业化动机
- 课程本质是方法论和案例教育，而非实时荐股，利益冲突风险相对较低
- 不存在证券投顾资质，所有观点属于个人分享
- **使用限制**：所有内容仅用于学习方法论和分析框架，不作为个股买卖依据

## 7. Skill 使用规则

- **可用于**：
  - 散户研究框架的自检（六问、财务排雷、五类机会分类）
  - 公司类型识别和对应研究重点的提示
  - 买点/卖点/仓位纪律的执行参考
  - 心态和认知偏差的提醒框架（弱者/强者视角）
- **不可用于**：
  - 证明某只股票值得买（课程案例已知结果，不能反推）
  - 替代公告、财报、行情数据的事实来源
  - 作为唯一买卖依据
  - 直接引用个股观点作为分析依据（有幸存者偏差）

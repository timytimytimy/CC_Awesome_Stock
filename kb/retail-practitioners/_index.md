# 散户实践者索引

本目录用于补充“大人物/机构投资者”之外，更贴近普通投资者执行约束的公开实践者。

**定位**：只学习方法、仓位、组合、ETF 替代、心理承受力和复盘习惯；不复制持仓，不把博主观点当成事实证据，不用作直接荐股依据。

## 使用顺序

1. 先读 `source-quality.md`，确认是否满足准入条件。
2. 再读对应实践者档案的“适合散户学习的部分”和“不可复制的部分”。
3. 在报告中只用于“散户可执行性”和“替代方案比较”。
4. 若实践者观点与数据、公告、财报、回测冲突，以可核验事实为准。

## 待补方向

- A 股财报拆解型博主：要求长期公开推理链和失败案例。
- 可转债/低风险套利实践者：要求解释规则、流动性和极端风险。
- 交易复盘型普通投资者：要求长期记录买卖前理由和事后复盘。
- 对 `watchlist` 来源做季度复核：若商业化/荐股风险增强，转入反面案例或移出正向索引。

## 不纳入方向

- 只发代码和涨停板复盘的短线号。
- 主要卖课、卖群、卖软件的账号。
- 以“内部消息”“主力”“庄家”为主要叙事的账号。
- 无法区分广告、投顾产品和个人观点的账号。

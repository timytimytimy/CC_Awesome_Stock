# 散户实践者来源质量规则

**目的**：把更贴近普通投资者的公开博主、实盘作者、ETF/基金实践者纳入知识库，同时避免把“人气”“喊单”“付费群”误当成研究质量。

**核心定位**：散户实践者只用于补充“普通人能不能执行、仓位和心理是否承受、是否有更简单的 ETF/基金替代方案”。不得把他们的观点当成事实证据、公司基本面证明或直接荐股依据。

## 1. 准入条件

进入 `kb/retail-practitioners/` 的对象至少满足 4 项：
- 有可回溯的公开内容，且不是只发短期喊单。
- 能清楚说明方法论，而不是只给股票代码。
- 经常讨论风险、仓位、回撤、失败或不适用场景。
- 对散户执行约束有帮助：资金规模小、信息少、精力少、情绪波动大。
- 没有承诺收益、内幕消息、稳赚话术。
- 商业化关系可识别：基金投顾、课程、社群、产品推广必须明示。

## 2. 硬性排除

出现任一项，默认不入库；如必须记录，只能放入“反面案例”：
- 承诺收益或暗示稳赚。
- 用“内部消息”“主力资金已确认”“老师带单”等方式诱导交易。
- 收会员费、VIP 权限费、服务费后直接荐股。
- 只展示盈利，不记录亏损、回撤和失败案例。
- 高频喊代码，不讲估值、仓位、退出条件。
- 推荐小市值、低流动性标的，同时拥有带单或社群动员能力。
- 主要内容是卖软件、卖课、卖群，并直接或变相提供个股买卖建议。

## 3. 评分表

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 公开可回溯 | 零散截图 | 有公开文章但不连续 | 长期公开文章/组合/计划 |
| 方法可复现 | 只给结论 | 有部分规则 | 有清晰输入、规则、退出条件 |
| 风险披露 | 几乎不讲 | 偶尔提醒 | 常态化讨论仓位、回撤、失败 |
| 散户适配 | 依赖资源/内幕/调研 | 部分适配 | 明确考虑普通人执行约束 |
| 利益冲突透明 | 不透明 | 可推断 | 主动说明产品/课程/投顾关系 |
| 反对意见 | 不允许质疑 | 偶尔回应 | 主动说明不适用场景 |

建议使用：
- `10-12`: source_quality = high，但仍不得作为事实证明。
- `7-9`: source_quality = medium，可用于执行与组合参考。
- `4-6`: source_quality = low，只能作为观察样本。
- `0-3`: source_quality = watchlist 或反面案例。

## 4. Skill 使用权重

```
事实证据：公告 / 财报 / 行情数据 / 官方政策 / 数据脚本
方法论：kb/playbooks/ > kb/authors/ > kb/schools/
执行适配：journal/lessons/ > kb/retail-practitioners/ > 通用常识
```

散户实践者可以降低结论置信度，也可以提出 ETF/等待/分散替代方案；不得单独提高结论等级。

## 4.1 类型使用边界

| 类型 | 可用场景 | 禁用场景 |
|---|---|---|
| `index-plan` / `fund-education` | ETF/基金替代、分散、再平衡、费率和组合执行 | 单股背书、收益承诺 |
| `portfolio-journal` | 仓位、容错、组合相关性、复盘习惯 | 复制持仓、复杂衍生品建议 |
| `sentiment-watch` | 题材热度、涨停梯队、短线圈层话术观察 | 个股池、低吸/追高指令 |
| `narrative-watch` | 跨市场叙事、散户情绪、外盘映射线索 | 事实源、交易信号 |
| `us-market-watch` / `us-tech-sentiment` | 美股科技/中概/期权热点线索、A股映射辅助 | 期权操作、目标价、会员内容 |

## 5. 合规和安全提醒

证监会风险提示指出，“非法荐股”包括无资格机构或个人向投资者提供证券投资分析、预测或建议等直接或间接有偿咨询服务，也包括以“大 V”“老师”等名义招揽投资者、收取会员费或服务费后荐股。见：
- https://www.csrc.gov.cn/xiamen/c105637/c1318554/content.shtml
- https://www.csrc.gov.cn/beijing/c105537/c1257631/content.shtml

因此，本目录只沉淀公开方法论和执行习惯，不保存“买入某股”“跟随某人持仓”类内容。

## 6. 复核节奏

- `review_due` 默认 6 个月。
- 若发现商业模式、平台账号状态、合规风险或内容风格明显变化，提前复核。
- 若某实践者开始高频个股喊单或引导付费群，降级为 `watchlist`。

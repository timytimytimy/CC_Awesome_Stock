# A股分析 Skill

## 必读：启动自检

开始任何分析前，必须完成：
1. **读取个人化配置**：`config/personal-profile.yaml`（资金/风险/仓位规则/禁区/成本）和 `config/circle-of-competence.yaml`（能力圈）。文件不存在则提示用户复制 example 建档；存在但 `meta.owner` 为空则提示可能仍是默认值。
2. 读取 `journal/lessons/*.md` 全部教训（权重最高）
3. 读取 `journal/trades/*.md` 了解当前持仓与历史交易（避免重复推荐已持有标的；可运行 `data/scripts/journal_summary.py` 看行为偏见汇总）
4. **读取能力路由表** `kb/taxonomy/capability-matrix.yaml`：决定每个环节加载哪些视角。不再无脑全员交叉验证。
5. 扫描 `kb/authors/*.md` frontmatter 中 `review_due` 字段，若有档案已过期则提示用户
6. 确认本次分析周期（用户未指定时默认 `mid`）
7. 若使用散户博主/实践者观点，先读取 `kb/retail-practitioners/source-quality.md` 的准入和排除规则
8. 确认运行模式：`quick_scan` / `weekly_pick` / `deep_dive`
9. 若使用 subagent，先读取 `references/subagent-protocol.md`
10. 若进行主动选股或候选排序，先读取 `references/scoring-rubric.md`

**决策权重顺序**（必须遵守）：
```
journal/lessons/  >  kb/cases/  >  kb/playbooks/  >  kb/authors/  >  kb/schools/
```
`kb/retail-practitioners/` 是散户可执行性层，只能用于仓位、组合、ETF 替代、心理承受力和执行难度评估；不得替代公告、财报、行情数据、回测或用户自己的复盘。

> **特别说明**：`kb/playbooks/lihai-stock-research-checklist.md` 属于 **playbook 层**（不是 retail-practitioners 层），内容为研究方法论框架（硬否决/六问/20问/五类机会），权重等同于其他 playbook，可用于单股研究的方法论自检和机会分类，不受"散户实践者限制"约束。

## 强制约束（违反则报告无效）

约束分四层。**A 层（硬门）和 B 层（流程）是机械铁律，无例外**；**C 层管输出质量**；**D 层是视角调用规则——不再用"无脑全员交叉验证"，改为按能力路由表动态加载**。

### A 层 · 硬门（踩中即出局，无例外）

- **A1【禁立即买入】** 不允许给出"立即买入"建议；最终结论只能是 `强观察 / 可小仓试错 / 等待验证 / 放弃 / 跟踪事件` 五选一。
- **A2【宏观闸门】** 若信用周期=衰退 或 市场温度=极冷 → 候选股最高 B 档，A 档禁用。信用周期=过热 → 成长股提升风险扣分。
- **A3【行业位置闸门】** 行业位置标签="高位过热"或"高位回调" → 该行业所有候选股最高 C 档。标签="价值陷阱风险" → 必须有明确反转催化剂才能入池。
- **A4【财报闸门】** 财报体检总分 < 50 → 强制"放弃"；50-69 → 最高 C 档；CFO/净利润 < 0.5 → 风险扣分至少 -10；ROE 近 5 年有亏损年份 → 长期价值派路径直接排除；扣非/净利润 < 0.7 → 必须列入反对意见。
- **A5【禁区过滤】** 候选股命中 `personal-profile.yaml` 的 `exclusions` → 阶段 3 直接排除，说明原因。
- **A6【能力圈门槛】** 候选股所属行业能力圈评分决定档位上限：level≥3 可进 A 档；level=2 最高 B 档；level=1 进 B 档需更高置信度；level=0 最高 C 档。
- **A7【里海硬否决】** 阶段 4 先过 `kb/playbooks/lihai-stock-research-checklist.md` 的"硬否决清单"（11条）；命中任意一条 → 直接放弃，不做深度分析。
- **A8【错题命中】** 候选股形态/逻辑命中 `journal/lessons/*.md` 历史错题模式（FOMO 追高、亏损加仓等）→ 必须显式引用该 lesson 并降档或提升风险扣分。

### B 层 · 流程义务（必须执行，不得跳过）

- **B1【宏观】** 阶段 1 必跑 `snapshot_macro.py`；报告 A 段写明信用周期阶段 + 市场温度评级，不得仅凭价格涨跌下结论。
- **B2【政策】** 阶段 1/2 必跑 `policy_track.py` 并读 `data/events/policy/_recent.md`；列出"真信号级"政策及影响行业。
- **B3【行业】** 阶段 2 必跑 `snapshot_industry.py`；报告 B 段标注每个候选行业的位置标签和近 3 年价格分位。
- **B4【财报】** 阶段 4 必跑 `financial_check.py`；报告 C 段列总分 + 五维评分 + 红旗清单 + CFO/净利润 + 5 年财务摘要。
- **B5【搜索】** 禁止以"知识截止日期"为由省略搜索。今日催化剂、板块动态、每只候选股的最新公告必须先 WebSearch；搜不到标注 `[数据缺失-搜索无结果]`，不得用假设替代。
- **B6【仓位换算】** A/B/C 档候选必跑 `position_calc.py`，把仓位上限换算成具体股数 + 金额 + 止损价。买不起一手/低于 min_order_amount/超 max_single_stock_pct → 标注"不可执行"并给替代方案。
- **B7【个人化】** 所有报告基于 `personal-profile.yaml` 算仓位、止损、成本；止损用 `risk.stop_loss_*`，不得用通用默认值。配置缺失时显著位置提示"未建个人档案，以下为通用假设"。

### C 层 · 输出与质量规则

- **C1【标注】** 每个判断标 `[事实]/[推断]/[假设]/[情绪]/[传闻]`；每个数据点带 `(as of YYYY-MM-DD)`。
- **C2【反对意见】** 每只候选股必须给反对意见，不允许空（来源见 D3 强制对手）。
- **C3【矛盾披露】** 搜索结果与价格走势矛盾（如大涨但有负面公告）→ 必须在报告显式列出。
- **C4【候选池披露】** 未用全市场脚本 → 只能声明"主线行业代表公司筛选"，不得声称穷尽扫描全 A 股。
- **C5【无结果分支】** 无候选通过过滤 → 必须明确输出"本轮无候选通过过滤"，不得硬凑。
- **C6【执行信号优先】** 报告前部必须给执行信号表：能否行动、动作类型、仓位上限、触发条件、止损/退出、加仓/降级/移出条件、最大反对理由。
- **C7【决策归属】** 可给具体信号建议，但必须说明最终执行由用户判断；不承诺收益，不输出"无条件立即买入"。
- **C8【回测标注】** 候选股所属策略无 `backtest/runs/` 支持 → 标注"未回测，仅方法论推断"。

### D 层 · 视角调用规则（由能力路由表驱动）

- **D1【路由优先】** 视角的选择由 `kb/taxonomy/capability-matrix.yaml` 按"分析环节 + 市场状态 + 股票类型"决定。**不把任何单一作者当权威，也不固定全部 4 流派交叉验证**——只加载路由命中的 3-5 个视角，路由 `avoid` 名单内的作者本环节不加载。
- **D2【结构化反对】** 每只候选股必须加载路由表 `bear_case` 指定的"强制对手"，作为最大反对理由的来源。对手要方法论上真正对立，不是走形式。
- **D3【置信度加权】** 作者观点按其档案 `confidence` 字段调权（high 1.0 / medium 0.7 / low 0.4）。low-confidence 作者（如任泽平）不得作为唯一依据；某环节 primary 视角全是 low → 显式声明"本环节缺高置信视角"。
- **D4【里海研究框架】** 阶段 4 用 `lihai-stock-research-checklist.md` 的"六问法"构建研究主线，"20问清单"做自检，"五类机会"（战略/战术/等待/放弃/可买入）标注候选性质。该清单属 playbook 层方法论，所有股票类型通用。
- **D5【散户实践者限制】** 散户博主/实践者只提供执行适配、ETF/基金替代、组合、心理纪律参考；不作单股买入依据，不单独提升结论等级。例外：`kb/playbooks/` 下的方法论框架（如里海清单）属 playbook 层，不受此限。
- **D6【利益冲突披露】** 引用的来源若有投顾产品、课程、社群、基金销售等商业化关系 → 报告必须披露并在风险检查中评估。
- **D7【subagent 限制】** subagent 只交证据/评分/疑点/反对意见；最终结论由主 agent 汇总；按流派/功能分工，不为每位作者单独角色扮演。

## 运行模式

| 模式 | 触发语 | 范围 | subagent |
|---|---|---|---|
| `quick_scan` | "大盘怎么看" / "现在什么主线" | 阶段 1→2，只给市场和方向 | 不使用 |
| `weekly_pick` | "全市场选股" / "给我本周候选" / "主动推荐股票" | 阶段 1→5，产出分档候选 | 可使用，按功能/流派分工 |
| `deep_dive` | "分析 600519.SH" / "这只怎么看" | 阶段 4→5，单股深度 | 可使用，按流派 lens 分工 |

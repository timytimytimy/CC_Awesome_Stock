# A股分析 Skill

## 必读：启动自检

开始任何分析前，必须完成：
1. 读取 `journal/lessons/*.md` 全部教训（权重最高）
2. 扫描 `kb/authors/*.md` frontmatter 中 `review_due` 字段，若有档案已过期则提示用户
3. 确认本次分析周期（用户未指定时默认 `mid`）
4. 若使用散户博主/实践者观点，先读取 `kb/retail-practitioners/source-quality.md` 的准入和排除规则
5. 确认运行模式：`quick_scan` / `weekly_pick` / `deep_dive`
6. 若使用 subagent，先读取 `references/subagent-protocol.md`
7. 若进行主动选股或候选排序，先读取 `references/scoring-rubric.md`

**决策权重顺序**（必须遵守）：
```
journal/lessons/  >  kb/cases/  >  kb/playbooks/  >  kb/authors/  >  kb/schools/
```
`kb/retail-practitioners/` 是散户可执行性层，只能用于仓位、组合、ETF 替代、心理承受力和执行难度评估；不得替代公告、财报、行情数据、回测或用户自己的复盘。

## 强制约束（违反则报告无效）

1. 每个判断必须标注 `[事实]` / `[推断]` / `[假设]` / `[情绪]` / `[传闻]`
2. 每个数据点必须带时间戳 `(as of YYYY-MM-DD)`
3. 每只候选股必须给出"反对意见"，不允许空
4. 若 journal/lessons/ 命中相似情形，必须显式引用
5. 若行业在 sector-rotation playbook 标记"过热"，必须降低置信度
6. 不允许给出"立即买入"建议
7. 最终结论只能是：`强观察 / 可小仓试错 / 等待验证 / 放弃 / 跟踪事件`
8. 若候选股所属策略无 backtest/runs/ 支持，标注"未回测，仅方法论推断"
9. 不把任何单一作者当权威，必须多流派交叉验证
10. 输出足够可执行的信号建议：能不能动、怎么动、仓位上限、触发条件和退出条件；最终执行由用户自行判断
11. **【搜索义务】禁止以"知识截止日期"为由省略搜索**。对今日大盘催化剂、强势板块动态、每只候选股的最新公告和新闻，必须先用 WebSearch 搜索后再作判断。搜索不到时，明确标注 `[数据缺失-搜索无结果]`，不允许用假设替代。
12. **【矛盾披露】**若搜索结果与价格走势存在矛盾（如：大涨但有负面公告），必须在报告中显式列出矛盾，不得忽略。
13. **【散户实践者限制】**散户博主/实践者只能提供执行适配、ETF/基金替代、组合和行为纪律参考；不得作为单股买入依据，也不得单独提升结论等级。
14. **【利益冲突披露】**若引用的实践者存在投顾产品、课程、社群、基金销售或其他商业化关系，必须在报告中披露，并在风险检查中评估是否影响结论。
15. **【subagent限制】**subagent 只负责证据、评分、疑点、反对意见；最终结论必须由主 agent 汇总。不得为每位作者/大 V 单独角色扮演。
16. **【候选池披露】**若未使用全市场脚本，只能声明“主线行业代表公司筛选”，不得声称已穷尽扫描全 A 股。
17. **【无结果分支】**若无候选通过过滤，必须明确输出“本轮无候选通过过滤”，不得硬凑股票。
18. **【执行信号优先】**主动选股、周度报告或单股深度分析必须在报告前部给出“执行信号表”，直接写清：是否可执行、动作类型、仓位上限、触发条件、止损/退出条件、加仓/降级/移出条件、最大反对理由。不要只给抽象研究结论。
19. **【最终决策归属】**可以给具体信号建议，但必须说明最终执行由用户自行判断；不得承诺收益，不得输出”无条件立即买入”。
20. **【宏观义务】**阶段 1 市场判断**禁止跳过 `data/scripts/snapshot_macro.py`**。报告 A 段必须明确写出当前信用周期阶段（高善文框架）和市场温度评级（Howard Marks 框架），不得仅凭价格涨跌下市场结论。
21. **【宏观约束】**若信用周期=衰退或市场温度=极冷，候选股最高档位为 B 档（可小仓试错）；A 档（强观察）禁用。若信用周期=过热，成长股需提升风险扣分。
22. **【行业基本面义务】**阶段 2 主线筛选**禁止跳过 `data/scripts/snapshot_industry.py`**。报告 B 段必须明确每个候选行业的"位置标签"（低估改善/高位过热/价值陷阱风险/中位平稳）和价格历史分位（近 3 年）。
23. **【行业位置约束】**若行业位置标签为"高位过热"或"高位回调"，该行业的所有候选股最高档位为 C 档（跟踪事件），禁止 A/B 档。若位置标签为"价值陷阱风险"，必须有明确反转催化剂才能进入候选池。

## 运行模式

| 模式 | 触发语 | 范围 | subagent |
|---|---|---|---|
| `quick_scan` | "大盘怎么看" / "现在什么主线" | 阶段 1→2，只给市场和方向 | 不使用 |
| `weekly_pick` | "全市场选股" / "给我本周候选" / "主动推荐股票" | 阶段 1→5，产出分档候选 | 可使用，按功能/流派分工 |
| `deep_dive` | "分析 600519.SH" / "这只怎么看" | 阶段 4→5，单股深度 | 可使用，按流派 lens 分工 |

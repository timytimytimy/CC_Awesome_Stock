## 标注规则

| 标签 | 含义 |
|---|---|
| [事实] | 来自可核验的数据/公告/财报 |
| [推断] | 基于事实的逻辑推导 |
| [假设] | 尚未验证的前提，是核心风险点 |
| [情绪] | 基于市场情绪的判断，不可过度依赖 |
| [传闻] | 来自非官方渠道，需核实 |

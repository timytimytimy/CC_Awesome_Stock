# 主动选股评分规则

评分用于排序候选股，不用于生成“立即买入”建议。最终结论仍只能是：
`强观察 / 可小仓试错 / 等待验证 / 放弃 / 跟踪事件`。

## 总分结构

| 模块 | 分值 |
|---|---:|
| 市场环境 | 0-20 |
| 行业/主线强度 | 0-20 |
| 公司质量 | 0-20 |
| 趋势/资金 | 0-15 |
| 催化剂可验证性 | 0-15 |
| 回测/历史案例支持 | 0-10 |
| 风险扣分 | 0 到 -30 |
| 散户执行扣分 | 0 到 -20 |

## 加分规则

### 市场环境 0-20
- A 状态：16-20
- B 状态：8-15
- C 状态：0-7，原则上不进入新仓
- D 状态：0-10，仅允许逆向赔率小仓观察

### 行业/主线强度 0-20
- 政策、产业、资金三者共振：16-20
- 两项共振：10-15
- 单纯资金或单纯传闻：0-9
- 已明显过热：最高 8

### 公司质量 0-20
- 真实收入利润、现金流匹配、行业地位清楚：16-20
- 财务尚可但核心假设未验证：8-15
- 亏损、现金流差或主题收入占比低：0-7

### 趋势/资金 0-15
- 中期上升趋势且未明显追高：11-15
- 横盘蓄势或回踩支撑：6-10
- 放量急涨后追高或下降趋势：0-5

### 催化剂可验证性 0-15
- 1-2 个季度内有公告、订单、财报、政策落地可验证：11-15
- 有催化但时间不清：6-10
- 只有市场叙事或传闻：0-5

### 回测/历史案例支持 0-10
- 有同策略回测或相似案例：7-10
- 只有方法论支持：3-6
- 无支持：0-2，并标注“未回测，仅方法论推断”

## 扣分规则

### 风险扣分 0 到 -30
- 每个红色风险项：-8
- 每个黄色风险项：-3
- 重大未披露负面、财务造假、ST、实控人风险：直接 `放弃`
- 搜索发现价格走势与公告/财报矛盾：至少 -8

### 散户执行扣分 0 到 -20
- 流动性差或需要高频盯盘：-5 到 -10
- 个股方案不明显优于 ETF/龙头/等待：-5 到 -10
- 依赖复杂工具、衍生品、极高波动：-5 到 -15
- 主要线索来自 watchlist 博主/付费圈/未核实传闻：-10 到 -20

## 档位

| 档位 | 条件 |
|---|---|
| A 档 强观察 | 总分 >= 70，且无红色风险，最多 3 只 |
| B 档 可小仓试错 | 总分 >= 60，红色风险不超过 1 个，最多 3 只 |
| C 档 跟踪事件 | 总分 45-59，或关键假设未验证，最多 5 只 |
| 等待验证/放弃 | 总分 < 45，或触发一票否决 |

若没有候选股达标，必须明确输出：`本轮无候选通过过滤`。

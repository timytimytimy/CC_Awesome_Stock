# 数据源研究与优化方案

> 2026-05-22 调研。背景：本系统单一依赖 akshare，本轮多次踩坑——CPI/M2/社融的
> 金十源冻结数月、东财接口常被墙、美联储利率无当期源。业界共识也印证单一数据源
> 是明确风险（连 Tushare Pro 都曾突发停运）。本文给出**免费优先**的优化方案。

## 1. 问题本质

akshare 不是"一个数据源"，而是**几十个上游网站的聚合器**（统计局/东财/同花顺/新浪/
金十/雪球/申万…）。任何一个上游改版或停更，对应接口就静默失真。本系统的数据可靠性
闸门（`data_health.py`）能**识别**问题，但识别 ≠ 有数据。真正的解法是**冗余**。

## 2. 免费数据源调研

| 数据源 | 成本 | 注册 | 当期可用性 | 擅长 | 短板 |
|---|---|---|---|---|---|
| **akshare** | 全免费 | 否 | 视上游而定 | 覆盖最广（行情/宏观/财报/政策/行业） | 上游改版即失效；东财接口常被墙 |
| **baostock** | 全免费 | 否（匿名 login） | ✅ 实测当期 | 日K线、财报、货币供应/利率 | 无实时快照、无 PMI/PPI/CPI |
| **tushare** | 免费版积分受限 | 是（+积分） | 一般 | 数据规范、质量高 | 免费版调用受限；**曾突发停运** |
| **FRED**（美联储经济数据） | 免费（需 API key） | 是（免费） | ✅ 权威 | 美国宏观（联邦基金利率等） | 仅海外数据 |
| **巨潮 cninfo** | 免费 | 否 | ✅ 官方 | 财报/公告/业绩预告（官方披露） | 接口少、需自行解析 |
| efinance | 全免费 | 否 | 视东财而定 | A股/美股/分钟线 | 包的是东财，同样被墙风险 |

**关键发现**：`baostock 0.9.10 本项目已安装**，且实测数据当期——
茅台 K线到 2026-05-21、2026Q1 财报、货币供应到 2026-04 全部正常。
它是**零新增依赖**的现成第二供应商。

## 3. 优化方案（分四层，免费优先）

### Layer 1 · akshare 内部择优（零成本，最先做）

akshare 同一类数据常有多个上游变体，优先用稳定的：
- **宏观**：统计局源（`macro_china_cpi/ppi/pmi/money_supply`）✅ 已完成换源；
  金十日历源（`*_monthly/*_yearly`）已弃用。
- **财报**：优先同花顺/新浪（`*_ths`/`*_sina`），少用东财（`*_em`，被墙风险高）。
- **行情**：快照已是 `spot_em` 失败回退 `spot`；K线用新浪源。

### Layer 2 · baostock 作为第二供应商（零新增依赖，强烈推荐）

为最关键的三类数据建"主源 → 备源"回退：

| 数据 | 主源 | 备源 | 说明 |
|---|---|---|---|
| 日 K 线 | akshare（新浪） | baostock `query_history_k_data_plus` | baostock 实测当期 |
| 财报 | akshare（同花顺） | baostock `query_profit/balance/cash_flow_data` | baostock 财报口径干净稳定 |
| 货币供应 | akshare（统计局） | baostock `query_money_supply_data_month` | 实测 M2 到 2026-04 |

主源取数失败或被数据闸门判定严重过期时，自动回退备源。

### Layer 3 · FRED 修复美联储利率（一次免费注册）

`macro_bank_usa_interest_rate` 冻结在 2025-07，akshare 无替代。
FRED（美联储官方经济数据库）的 `DFF`/`FEDFUNDS` 序列是权威免费源，
申请免费 API key 即可。这是唯一值得为之引入外部源的缺口。

### Layer 4 · tushare 作为可选增强（非免费优先）

免费版积分受限、且有停运先例，对"免费优先"定位性价比不高。
保持 README 现状（标为可选），不作为主力。

## 4. 落地建议

- [ ] **抽象 provider 回退层**：每个 getter `主源→备源` 自动回退；记录实际用了哪家。
- [ ] `data_health.py` 每行标注 `provider`，接口失效时一眼看出该换源。
- [ ] Layer 2 优先：日K线 + 财报接 baostock 备源（依赖已就绪，改动集中在 `stock_data/`）。
- [ ] Layer 3：`stock_data/macro.py` 的 `get_fed_rate` 接 FRED。
- [ ] 数据源巡检：定期跑 `data_health.py`，接口冻结早发现。

> 不做：北上资金（交易所 2024-08 已永久停止披露实时净额，无解）。

## 5. 一句话结论

**先做 Layer 1+2**——全免费、零新增依赖（baostock 已装），就能让日K线/财报/货币供应
三类核心数据具备双源冗余。Layer 3（FRED）补美联储。tushare 不必急。
